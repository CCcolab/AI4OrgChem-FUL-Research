### 文件内容与用途

| 文件 | 内容 | 主要用途 |
|---|---|---|
| STATE.npz | 工作基、AO重叠、轨道系数、占据、密度及相应算符数组 | 保存数组复核 |
| STATE_DEFINITION.json | 基组、电子数、角色分组、空间与占据定义 | 核对所使用的模型 |
| VALIDATION.json | 原终验指标、空谱、可靠性带及附加诊断 | 检查原数值记录 |

## 保存数组复核

保存数组复核针对当前列出的五份数值态，文件身份按SHA核对。页面文字与导航在调试阶段持续调整。

```text
git -c core.autocrlf=false clone https://github.com/CCcolab/AI4OrgChem-FUL-Research.git
```

在仓库根目录按requirements-verify.txt准备Python与NumPy，然后执行：

```text
python -X utf8 scripts/verify_saved_state.py --root . --basis all
```

脚本读取保存的密度、轨道、h/J/K和Fock，检查密度重建、能量账本、两类映射残差、占据—空残差、身份及全部空谱。输出为机器可读报告，返回码0表示此层复核通过。从几何重构、重新生成积分和新的源SCF另按独立量化任务组织。

各态的残差、源能量及SCF周期集中列于[五基组数值复核摘要](five-basis-results.zh-CN.md)。

<details>
<summary>终验精度与特殊记录（技术补充）</summary>

各基组按各自原始终验记录和数值可靠性带验收。STO-3G及6-31G保留其原数值路径；较大基组的直接J/K路径保留相应精度对照。

| 基组 | 需要结合原记录读取的补充内容 |
|---|---|
| STO-3G | 原四种子FUL-3终验及33个空方向 |
| 6-31G | M7自身源终验、身份桥及100个空方向 |
| 6-31G(d) | 目标基组直接J/K精度对照及170个空方向 |
| 6-31G(d,p) | 三层终验及17项重叠表示精确绑定检查，覆盖203个空方向 |
| 6-31++G(d,p) | 同一原27周期候选固定W、密度和轨道后的OMP1／BLAS1三层精度终验及28项独立数组检查，覆盖270个空方向 |

6-31++G(d,p)的OMP1步骤核对同一候选的Fock求值稳定性；原SCF轨道及占据保持。其记录分别保存历史SCF使用的Fock与当前OMP1终验Fock，能级读取规则见[轨道与工作簿使用说明](author-review-guide.zh-CN.md)。

数值精度对照、保存数组复核与严格积分／精确根认证按不同证据层级登记。
