# 轨道与工作簿使用说明

本页说明怎样用Excel或WPS查看五个基组的轨道、能级与验收结果。

## 打开与选择

1. 在[轨道工作簿与数值包下载](../downloads/README.md)中选择基组，打开对应工作簿。
2. 先看“概览”，再按下表选择所需信息。
3. 需要完整精度或原始数组时，下载同一基组的完整ZIP。

| 查阅目标 | STO-3G工作簿 | 其余四个工作簿 |
|---|---|---|
| 研究结论与验收 | 概览 | 概览、验收结果 |
| 轨道占据与逐列能级 | 轨道占据 | 轨道占据 |
| 完整AO轨道系数 | 轨道系数 | 轨道系数 |
| 接键轨道系数 | 轨道系数，结合本基组成果页的接键MO列号 | 接键轨道系数 |
| 全部实际空轨道谱 | fresh空补谱 | fresh空补谱 |
| 计算原理、几何与AO | 中文成果页及ZIP中的几何表、系数表AO标签 | 计算原理、几何与AO |

每个基组的中文成果页均列出实际接键MO列号、能级与系数示例，可从[首页五基组成果对照](../README.md#五基组成果对照)进入。

## 两种能级怎样读取

| 表内名称 | 对应内容 | 查阅用途 |
|---|---|---|
| 系数对应能级（mapped） | 与保存的轨道系数列及实际占据逐列对应的能级 | 对照某个MO的系数、占据和能级 |
| 验收空谱（fresh） | 最终实际占据的组内空补空间谱 | 核对全部空方向的C2判据 |

两类数据按各自表头和编号读取。空补谱的行号与保存MO的列号分别定义；用于C2的最低空根在验收表中单独列示。

## 编号、精度与已有页签

- 中文成果页的“保存MO列”从1计数；工作簿和CSV按各自表头的起始编号读取，对齐同一保存列。
- Excel显示位数可以调整；完整有效数字保存在CSV和原数值态中。
- 早期工作簿中的“三基组对照”或“四基组对照”是其形成时的摘要；当前五个基组的总览以在线[首页五基组成果对照](../README.md#五基组成果对照)为准。
- 原子标签的对应关系见[原子编号说明](atom-numbering.zh-CN.md)。程序复核及精度控制见[数值复核与原始数据](reproducibility.zh-CN.md)。
