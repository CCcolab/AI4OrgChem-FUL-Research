# 研究成果与适用范围

当前已完成NBA在STO-3G、6-31G、6-31G(d)、6-31G(d,p)、6-31++G(d,p)五个基组下的登记源条件FUL建态。共同条件为独立重建平面几何、96电子、全电子非相对论计算、有限原子中心Gaussian轨道基组，含d函数时采用球谐5D表示。

| 基组类别 | 已完成实例 | 覆盖的构造因素 |
|---|---|---|
| 最小基组 | STO-3G | 原四种子FUL-3基线 |
| 径向扩展 | 6-31G | 完整片段工作基及空响应选择 |
| 重原子极化 | 6-31G(d) | 重原子d方向及普通块松弛 |
| 氢原子极化 | 6-31G(d,p) | 真实分子H的p方向 |
| 重原子与氢弥散 | 6-31++G(d,p) | 弥散方向、度量条件及双侧谱容量 |

“任何基组”研究采用跨基组一致的构造和验收框架推进。当前完成结论对应上述五个有限实例；其他基组在加入成果目录时分别完成同一套构造与验收。实际转移维数由独立性、响应及容量决定，当前返回为1/1/1和3/4/3，各自绑定明确空间及目标分支。

真实NBA的AO基组、辅助参考的探针基组及LFMO／NBO表示分别记录。已有STO基线采用独立片段／Kost链，推广态采用已登记的投影、补齐和响应构造。几何、原子映射、角色归属、实际占据及四种子身份均随数值态保存。

当前提供轨道系数、能级、密度、Fock、全部空谱及验收证据，供研究者查阅、复核和开展后续同协议研究。数值可靠性带依据精度对照与保存算术评估；严格积分包围和精确根证明属于另外的认证层级。

FUL/PDSI作用能研究采用同一实际工作空间、响应子空间、归属和电子账本，仅改变预先指定通道。表列源能量用于各态账本，跨基组研究按共同协议另行组织。

源条件模型的密度与能量解释详见[源条件密度与能量的物理解释](supplementary/physical-density-diagnostics.zh-CN.md)。该页记录实测诊断和用途限制，与FUL建态判据分别呈现。
