# FUL定义与轨道构造

本页集中说明FUL模型、判据及五个基组的工作空间构造。各基组的成果介绍和轨道查阅见[首页五基组成果对照](../README.md#五基组成果对照)。

## FUL定义与判据

本项目的FUL电子态是固定NBA几何、实际AO基组、完整工作基W、组角色和占据规则下求得并保存的源条件数值态。

以AO重叠S、组内占据轨道O_g表示，采用组密度参数及RHF型Fock：

$$P=2\sum_g O_gO_g^\dagger,\qquad F[P]=h+J[P]-\tfrac12K[P].$$

条件设置作用于W表示的F/S通道。各保留组使用S_g=W_g†SW_g与F_g=W_g†F[P]W_g求解，完整条件度量为组内度量的块对角组合。分组电子数固定，MOM跟踪实际占据。AO积分保留实际分子与基组定义。

源总能量采用同一P及J/K：

$$E=\operatorname{Tr}(Ph)+\tfrac12\operatorname{Tr}(PJ)-\tfrac14\operatorname{Tr}(PK)+E_N.$$

**C1与`C1*`。** STO-3G接键块为四种子、四电子、两个双占和两个空轨道，采用原四维C1。其余四个基组采用`C1*`：保留四种子和四电子，纳入相关空方向；前三个推广态接键7维，弥散基组态接键14维，均为两个双占MO。占据账本属于模型设定，数值验收同时检查自洽、身份和空谱。

**C2。** 在最终自身密度的未位移Fock下，按各组条件度量和实际占据构造完整空补空间；所有实际空根须高于对应数值可靠性带。五个基组分别覆盖33、100、170、203和270个空方向，均通过。

**联合验收。** 密度重建、Fock和能量账本、占据—空残差、两类密度映射残差、能量三次确认、原0.5身份与全部C2均绑定同一最终候选。保存数组、占据映射及验收记录共同定义交付对象。

**系数与能级。** 系数对应能级与保存MO列逐列对应；验收空谱按最终实际占据的补空间单独列示。子空间身份按度量、支撑与重叠核对，允许相位和等占据空间内部旋转。

本模型的密度和源能量如何作物理解释、有哪些适用边界，见[源条件密度与能量的物理解释](supplementary/physical-density-diagnostics.zh-CN.md)。这些物理诊断与FUL建态判据分别呈现。


FUL条件参考态用于后续非成键σ–σ作用研究。FUL/PDSI比较按同一实际空间、响应子空间、归属及电子账本组织，仅改变指定通道；源能量按登记的辅助条件函数解释。

## 跨基组轨道构造

共同目标是在完整AO工作空间内保留四个切口种子，为四电子接键系统引入相关空方向，并在各自自身密度上完成源条件SCF和全部验收。

| 最终态 | 构造及新增自由度 | 接键空间 |
|---|---|---|
| STO-3G | 独立平面几何、片段参考、加帽／Kost与去探针 | 四种子，4维 |
| 6-31G M7 | 片段投影、完整空间补齐、R/G候选与Schur选择；登记df3父锚及共同参考 | 四种子＋1/1/1转移，7维 |
| 6-31G(d) M7 | 继承6-31G构造，补齐真实重原子d极化空间，求目标基组自身源SCF | 7维 |
| 6-31G(d,p) M7 | 在前态构造上补齐真实H的p极化方向，核验响应及容量，求自身源SCF | 7维 |
| 6-31++G(d,p) M14 | 补齐弥散AO、核验度量，扩展响应及池外方向，联合满足接键与普通σ供体容量 | 四种子＋3/4/3转移，14维 |

各转移方向来自对应普通σ空空间；角色转移同时改变接键块与供体块。因此空间定义、允许通道及保留补空间均随状态登记，源能量按各自模型解释。实际转移数由本次响应与容量结果确定。

6-31G(d)与6-31G(d,p)的新增极化自由度进入完整分子空间及片段松弛。6-31++G(d,p)针对普通σB负谱与接键容量联合选择，使额外弥散响应进入14维接键空间。

构造核验覆盖W满秩、片段支撑、σ/π类型、四种子保留及原0.5占据身份；源SCF在冻结的实际W上进行。最终自洽与全部空谱通过后登记成果，具体参数见[五基组数值复核摘要](five-basis-results.zh-CN.md)和各态定义。

原著切口为C1–N12、C13–C15；需求中的C14作为同一C15碳的别名登记。详见[原子编号说明](atom-numbering.zh-CN.md)。
