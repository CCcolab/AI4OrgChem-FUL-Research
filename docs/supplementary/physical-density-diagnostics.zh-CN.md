# 源条件密度与能量的物理解释

本页说明源条件FUL结果的物理解释及适用边界，记录五份保存组密度参数P在真实AO度量下的物理诊断。五份登记源条件FUL态的自洽、身份及全部空谱均已通过；下述物理诊断用于说明这些条件模型结果的用途，与FUL建态判据分别读取。

令S=LL†，物理白化密度为D=L†PL。普通电子体系的自旋求和1RDM满足0≤D≤2I、Tr(D)=N；闭壳层行列式另满足D²=2D。每个归一空间轨道最多容纳两个不同自旋电子，因而物理自然占据上界为2。

上表来自[五态保存数组复核原始报告（JSON）](../../verification/FIVE_BASIS_SAVED_ARRAY_VERIFICATION_20261106.json)，各原始VALIDATION.json中的物理诊断与状态继续保留。当前P的自然占据超过2，其用途为所声明辅助条件方程的组密度参数；将它直接解释为普通物理纯态、相关态或混态1RDM会违反占据上界。源能量为相应辅助条件函数值，物理态期望或可观测量的解释需要独立定义及证明。

源条件F/S按组设置。若占据列集合为O且G=O†SO可逆，归一非正交闭壳层Slater对应P_det=2O G⁻¹O†；这与当前组和密度具有不同定义。采用该密度需要另立自洽模型及用途，现有源条件数值态按原定义保存。

当前提供作者所需的登记FUL源条件态，普通物理RHF构造属于独立研究目标。该诊断作为用途说明保存，作者的两项FUL主判据及其推广定义见[FUL定义与轨道构造](../source-ful-definition.zh-CN.md)。
