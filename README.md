# NBA分子的FUL电子态：五个基组的建态成果

本项目承接[AI4OrgChem十四项论点／论据的独立验证研究](https://github.com/CCcolab/AI4OrgChem)，围绕Zhongheng Yu专著*Questioning Fundamental Principles of Organic Chemistry*开展FUL基组扩展研究。

原著第5.4.1—5.4.2节以NBA（N-benzylideneaniline）为对象，为研究非成键σ–σ作用建立了RHF/STO-3G下的FUL条件参考态，并报告较大基组的空轨道能级与接键占据问题。本研究面向“在任何基组下建立FUL电子态”的目标，将相关空LFMO纳入接键空间，采用一致规则核验构造、身份、自洽与全部空谱。

## 研究成果与适用范围

**五个基组的FUL源条件电子态均已建立，并通过同一终态的自洽、身份及全部空轨道正谱验收。**

每个基组均提供计算原理、完整轨道系数、占据与能级以及验收结果。读者可直接阅读中文成果页，用Excel／WPS查看完整轨道；CSV、原数值态和程序复核资料另在数据区提供。

五个基组使用同一独立重建的平面NBA几何、96个电子，采用全电子、非相对论的RHF型源条件模型；含d函数时使用球谐5D表示。

| 基组类别 | 已完成实例 | 覆盖的构造因素 |
|---|---|---|
| 最小基组 | STO-3G | 原四种子FUL-3基线 |
| 径向扩展 | 6-31G | 完整片段工作基及空响应选择 |
| 重原子极化 | 6-31G(d) | 重原子d方向及普通块松弛 |
| 氢原子极化 | 6-31G(d,p) | 真实分子H的p方向 |
| 重原子与氢弥散 | 6-31++G(d,p) | 弥散方向、度量条件及双侧谱容量 |

五个实例采用一致的验收规则，新增空 LFMO 的选择和数目按各基组的工作空间确定。
